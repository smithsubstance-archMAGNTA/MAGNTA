# MAGNTA Site Central

Este repositorio es la fuente local de verdad de MAGNTA: centro de datos,
memoria operativa y espacio de aterrizaje del conocimiento.

## Regla de entrada

Todo material nuevo llega primero a `01_ENTRADA`. Antes de moverlo a su destino,
se registra en `99_SISTEMA/Catalogos/MAGNTA_Indice_Maestro.xlsx`.

## Estructura

- `00_GOBIERNO`: reglas, decisiones y responsables.
- `01_ENTRADA`: captura pendiente de procesar.
- `02_CONOCIMIENTO`: conocimiento curado por dominio.
- `03_PROYECTOS`: trabajo con objetivo y entregable.
- `04_OPERACION`: procesos recurrentes y controles.
- `05_ACTIVOS`: recursos reutilizables.
- `06_PUBLICACIONES`: entregables aprobados.
- `90_ARCHIVO`: histórico e inactivos.
- `99_SISTEMA`: catálogos, plantillas y respaldos.

El modelo operativo completo está en
`00_GOBIERNO/MAGNTA_Manual_del_Site.docx`.
